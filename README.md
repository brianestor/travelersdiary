# Travelers Diary

Safari site for fixed-date departures. A reservation is a request the desk confirms. Nothing is charged online.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Copy `env.example` to `.env.local` and set `ADMIN_PASSWORD` before using the staff list at `/admin`.

Place the logo at `public/brand/logo.png` or `public/brand/logo.svg`. Until that file is there, the header shows the name.
